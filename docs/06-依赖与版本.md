## 2. Go 官方 SDK（探针 agent-2 实测）

### 精确坐标

| 用途 | module | version | go 指令 |
|---|---|---|---|
| A2A 协议 | `github.com/a2aproject/a2a-go/v2` | **v2.8.0** | `go 1.26.0` |
| MCP 协议 | `github.com/modelcontextprotocol/go-sdk` | **v1.8.0** | `go 1.25.0` |

- `github.com/modelcontextprotocol/go-sdk/mcp` **不是 module**，只是主 module 里的 package；`go list -m -versions` 该路径会失败，用 `go get github.com/modelcontextprotocol/go-sdk@latest` 正常。
- `github.com/a2aproject/a2a-go`（v0.3.15）是旧 v0.3 协议，与 v2 **类型不通用**；新代码只用 v2。
- `github.com/mark3labs/mcp-go`（v1.5.0）是第三方 SDK，API 与官方完全不同，**不要混 import**。
- 传递依赖（tidy 后）：`google/jsonschema-go v0.4.3`、`google/uuid v1.6.0`、`segmentio/asm v1.1.3`、`segmentio/encoding v0.5.4`、`yosida95/uritemplate/v3 v3.0.2`、`golang.org/x/{mod,oauth2,sync,sys,time}`。
- **全部纯 Go，无 cgo**；`CGO_ENABLED=0 go build ./...` 通过。

### 真实 API（与契约差异，重要）

| 契约 v1.0 假设 | 官方 v2.8.0 实际 | 处理 |
|---|---|---|
| JSON-RPC `message/send` | `SendMessage`（PascalCase） | 以官方为准 |
| `state:"completed"` | `TASK_STATE_COMPLETED` | 以官方为准 |
| `AgentCard.url` | `SupportedInterfaces []*AgentInterface` | 以官方为准 |
| 自写 SSE | SDK 内部 `sse.NewWriter`，`AgentExecutor.Execute` 返回 `iter.Seq2[a2a.Event,error]`，yield 事件即可 | 用官方 |
| `POST /tasks/{id}:cancel` | `POST /tasks/{idAndAction}` + `strings.CutSuffix(...,":cancel")` | **与简历 panic 的正解一致** |
| 自己挂冒号路由 | 禁止写 `mux.HandleFunc("POST /tasks/{id}:cancel", ...)` | 遵守 |

关键签名（源码位置见探针报告）：
```go
// a2asrv/agentexec.go
type AgentExecutor interface {
    Execute(ctx context.Context, execCtx *ExecutorContext) iter.Seq2[a2a.Event, error]
    Cancel(ctx context.Context, execCtx *ExecutorContext) iter.Seq2[a2a.Event, error]
}
// a2asrv
func NewHandler(executor AgentExecutor, options ...RequestHandlerOption) RequestHandler
func NewJSONRPCHandler(handler RequestHandler, options ...TransportOption) http.Handler
func NewRESTHandler(handler RequestHandler, opts ...TransportOption) http.Handler
func NewStaticAgentCardHandler(card *a2a.AgentCard, opts ...AgentCardHandlerOption) http.Handler
const WellKnownAgentCardPath = "/.well-known/agent-card.json"
// a2aclient
func NewFromCard(ctx context.Context, card *a2a.AgentCard, opts ...FactoryOption) (*Client, error)
func (*Client).SendMessage(ctx, *a2a.SendMessageRequest) (a2a.SendMessageResult, error)
func (*Client).SendStreamingMessage(ctx, *a2a.SendMessageRequest) iter.Seq2[a2a.Event, error]
// mcp
func NewServer(impl *Implementation, options *ServerOptions) *Server
func AddTool[In, Out any](s *Server, t *Tool, h ToolHandlerFor[In, Out])
func (*Server).AddTool(t *Tool, h ToolHandler)
func NewInMemoryTransports() (*InMemoryTransport, *InMemoryTransport)
func NewStreamableHTTPHandler(getServer func(*http.Request) *Server, opts *StreamableHTTPOptions) *StreamableHTTPHandler
func NewSSEHandler(getServer func(*http.Request) *Server, opts *SSEOptions) *SSEHandler
```
`mcp.Tool.InputSchema` 是 `any`；泛型 `AddTool` 留空会自动推断（JSON Schema 2020-12），raw `Server.AddTool` 需自己给 schema + 自己校验。

## 3. Java 官方 SDK（探针 agent-4 实测）—— **JDK 11 不可用**

### 精确坐标

| 库 | 坐标 | 最新稳定 |
|---|---|---|
| A2A | `org.a2aproject.sdk:a2a-java-sdk-bom` / `-spec` / `-server-common` / `-transport-jsonrpc` / `-reference-jsonrpc` | **1.5.1.Final** |
| MCP | `io.modelcontextprotocol.sdk:mcp`（1.0.0+ 为空壳，类在 `mcp-core`） | **2.2.0** |
| JSON | `com.fasterxml.jackson.core:jackson-databind` | **2.17.2**（Java 8 字节码） |
| JSON | `com.google.code.gson:gson` | **2.11.0**（Java 7 字节码） |

查证方式：`https://repo1.maven.org/maven2/org/a2aproject/sdk/a2a-java-sdk-bom/maven-metadata.xml` → HTTP 200。
`search.maven.org` 索引滞后返回 0，**不可信**；BOM 是 pom packaging，`dependency:get` 须显式 `:pom`。

### 决定性结论

- A2A 与 MCP 官方 SDK **所有已发布版本 class major=61 (Java 17)**，且 `AgentCard`/`Task`/`McpSchema$Tool` 都是 `java.lang.Record`，**JDK 11 无降级空间**。
- 实证：`SdkUsage.java`（真实调用 SDK API）JDK 11 编译报 `类文件具有错误的版本 61.0, 应为 55.0`；**JDK 22 编译 + 运行成功**。
- MCP 2.2.0 传递依赖 **Jackson 3** `tools.jackson.core:jackson-databind:3.1.8`，与 `com.fasterxml.jackson.core` 不兼容。
- A2A Java 完整 server 装配依赖 **Jakarta CDI / Quarkus + `@PublicAgentCard`**，不是纯 `new`。

### 本地采用方案（诚实分层）

| 模块 | 运行时 | 依赖 | 理由 |
|---|---|---|---|
| 控制面 control-plane | **JDK 11** | Jackson 2.17.2 + `com.sun.net.httpserver` | 业务逻辑自研，拖 Quarkus/CDI 会失真；探针已跑通 9 项 HTTP 用例 |
| MCP 注册中心 mcp-registry | **JDK 11** | Jackson 2.17.2 + HttpServer | 同上；OpenAPI 转换是自研核心 |
| **Java SDK** | **JDK 22** | `org.a2aproject.sdk:a2a-java-sdk-spec:1.5.1.Final` + 官方 MCP | 满足"引用官方 SDK"；本机有 JDK 22 |
| **Java 示例 Agent** | **JDK 22** | 同上 | 用官方 SDK 实现真实 A2A Agent |

- classpath 模式下 `com.sun.net.httpserver` 在 JDK 11 直接可用；若模块化需 `requires jdk.httpserver;`。
- **编码**：pom 必须 `<project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>` + compiler `<encoding>UTF-8</encoding>`；HTTP 读写显式 `StandardCharsets.UTF_8`；响应头 `charset=UTF-8`。

### JDK 11 工程 pom 片段（已验证 BUILD SUCCESS）

```xml
<properties>
  <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  <project.reporting.outputEncoding>UTF-8</project.reporting.outputEncoding>
  <maven.compiler.release>11</maven.compiler.release>
  <jackson.version>2.17.2</jackson.version>
</properties>
<dependencies>
  <dependency><groupId>com.fasterxml.jackson.core</groupId><artifactId>jackson-databind</artifactId><version>${jackson.version}</version></dependency>
</dependencies>
<build><plugins><plugin>
  <groupId>org.apache.maven.plugins</groupId><artifactId>maven-compiler-plugin</artifactId>
  <version>3.13.0</version>
  <configuration><release>11</release><encoding>UTF-8</encoding></configuration>
</plugin></plugins></build>
```

## 4. Python 官方 SDK（探针 agent-3 实测）—— **必须锁 0.3.x / 1.x**

### 版本决策（重要：最新版反而不能用）

PyPI 最新是 `a2a-sdk==1.3.0`、`mcp==2.3.0`，但**两者都是破坏性重写**：

| 库 | 1.x / 2.x 的 breaking change（实测） |
|---|---|
| `a2a-sdk 1.x` | `a2a.server.apps` **整个模块删除**（ModuleNotFoundError）→ 改 `a2a.server.routes`；`a2a.types` 从 pydantic 换成 **protobuf 类** `a2a_pb2.*`；`DefaultRequestHandler` 多必填 `agent_card`、入参变 `SendMessageRequest`；`a2a.client.legacy` 删除 |
| `mcp 2.x` | `import mcp.server.fastmcp` **直接抛异常**，SDK 自带提示 "FastMCP was renamed to MCPServer ... or pin 'mcp<2'"；字段蛇形化+alias（`input_schema`）；类型搬到独立包 `mcp-types`；HTTP 客户端换成 `httpx2` |

**冻结版本**（`requirements.txt`）：
```txt
a2a-sdk[http-server]==0.3.26
mcp==1.30.0
uvicorn>=0.31.1
fastapi>=0.115
httpx>=0.27
pydantic>=2.0
```
实测依赖树：fastapi 0.163.0 / starlette 1.10.0 / uvicorn 0.54.0 / httpx 0.28.1 / pydantic 2.14.3 / sse-starlette 3.7.0 / anyio 4.16.0 / protobuf 7.36.2 / google-api-core 2.44.0 / pywin32 312。Python 3.12.4 全兼容。
安装建议用清华镜像：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt`（原生 pypi.org 慢，`pip index versions` 本机卡死）。

### 真实 API（0.3.26 / 1.30.0）

```python
# a2a.types 是 pydantic 模型（snake_case 定义 + camelCase alias）
# Part 是 RootModel：Part(root=TextPart(text=...))
from a2a.server.apps import A2AStarletteApplication, A2AFastAPIApplication, A2ARESTFastAPIApplication
app = A2AStarletteApplication(agent_card, http_handler).build()  # -> Starlette
# build() 自带 / 、/.well-known/agent-card.json 、/.well-known/agent.json
from a2a.server.request_handlers import DefaultRequestHandler
handler = DefaultRequestHandler(agent_executor, task_store)
from a2a.server.tasks import InMemoryTaskStore
# AgentExecutor 精确签名（agent_executor.py:15/32，ABC）
async def execute(self, context: RequestContext, event_queue: EventQueue) -> None: ...
async def cancel(self, context, event_queue) -> None: ...
# 事件用 await event_queue.enqueue_event(...) 发布
from a2a.client import A2AClient   # 0.3.26 里 deprecated 但可用
await client.send_message(SendMessageRequest)
async for ev in client.send_message_streaming(SendStreamingMessageRequest): ...

# mcp 1.30.0
from mcp.server.fastmcp import FastMCP
mcp = FastMCP("name")
@mcp.tool(name=..., description=...)
def fn(...): ...
await mcp.list_tools(); await mcp.call_tool(name, arguments)
mcp.run(transport='stdio'|'sse'|'streamable-http')
mcp.streamable_http_app()
```

### 坑

- `pip index versions` 本机卡死（pip 24.0 实验命令 + pypi.org 慢）；用 PyPI JSON API 查版本 + 清华镜像装。
- uvicorn 必需：A2A 的 `build()` 只给 ASGI app；mcp 的 `streamable_http_app()` 也要挂 uvicorn。
- 中文 Windows：PowerShell `>` 重定向是 UTF-16LE（日志会变"二进制"）；用 `Out-File -Encoding utf8` + `$env:PYTHONIOENCODING='utf-8'`；stderr 中文会被包成 NativeCommandError（脚本其实成功）；**stdio MCP 的 stdout 是协议通道，绝不能 print 调试信息**；HTTP 验证用 Python httpx 而非非交互模式的 Invoke-WebRequest。
- 探针实测：uvicorn 真起 127.0.0.1:9999 后 `message/send`、`message/stream`（两条 SSE）、官方 `A2AClient` 往返均成功；MCP `list_tools/call_tool` 与真实 stdio 往返（含中文 `你好, 探针!`）成功。
