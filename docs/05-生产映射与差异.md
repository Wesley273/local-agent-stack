# 05 · 生产映射与本地差异（诚实边界）

> 逐项列出「本地实现」与「简历里的华为云生产系统」的对应关系，
> 明确哪些是等价替代、哪些是刻意简化、哪些没有复刻。**不含虚构内容**。

---

## 1. 总体原则

| 维度 | 生产（简历原型） | 本地（本仓库） | 性质 |
|---|---|---|---|
| 协议合规 | 内部 A2A/MCP 实现 | **官方 A2A / MCP SDK** | 更好：规范对齐 |
| L7 数据面 | Envoy + Golang cgo 插件 | Go `net/http` 过滤器链 | 等价语义替代 |
| 隔离 | microVM / Knative / K8s | 本地多进程 + 端口 | 简化（无 gcc/Docker） |
| 存储 | MySQL / Redis 集群 | JSON 文件 + 内存（Store 接口抽象） | 可替换替代 |
| 配置 | CRD / DCC / reconcile | 控制面 `/v1/config` revision 快照 + 轮询 | 等价语义替代 |
| 认证 | 企业 IAM / mTLS | API Key + grants | 简化 |
| 可观测 | ClickHouse / ES / Thanos / OTel | 内存 span store + JSON 端点 | 简化 |
| LLM | 真实模型服务 / vLLM | Mock LLM（可切 echo/mock） | 替身 |

## 2. 逐项对照

### 2.1 AI 网关

| 生产组件 | 本地对应 | 差异说明 |
|---|---|---|
| Envoy Golang 插件（cgo ABI） | `pkg/a2a/filter.go` 的 `StreamFilter` 接口 | 接口逐阶段对齐：`DecodeHeaders`/`DecodeData`/`EncodeHeaders`/`EncodeData`/`OnDestroy`；状态 `Continue`/`StopAndBuffer`/`StopAndReply`/`LocalReply` |
| `SendLocalReply` | `FilterContext.AppendEncodedData` | **刻意修正**：生产里它掐断 SSE，本地禁止在 `ResponseStarted` 后写新 HTTP 状态 |
| `AddEncodedData` + `api.Continue` | 同上 + `Continue` | 完全一致 |
| filter 每请求新建（OOM 根因） | `sync.Pool` + `Reset()` + `OnDestroy()` | 修正，并有 `/v1/admin/pool` 计数 |
| `config_dump` / jq 排查 | `/v1/admin/config` + `/v1/admin/traces` | 结构化替代 |
| DestinationRule / VirtualService / EnvoyFilter | 控制面 `models[]`/`agents[]` 快照 | 无 xDS，用 HTTP 轮询 |
| `created-by: agentrun` reconcile 覆盖手改 | 数据面不读本地运行时配置 | 完全一致（E21） |
| Istio `EnvoyFilter apply 409` | 单向下发，无多写方 | 规避 |
| `sidecar.istio.io/proxyMemoryLimit` | Go 进程内存 + pprof 端点 | 简化 |
| Spring Boot Agent 注册中心 | Java `HttpServer` + Jackson | 无 Spring 容器，接口一致 |
| `A2A_AGENT_INFO/VERSION/SKILL/SKILL_TAG/AUTH_POLICY/WEBHOOK/APP_GRANT` 表 | `config/snapshot.json` 的 agents/policies/grants | 表→JSON，字段对应 |
| Redis 令牌桶 | 内存滑动窗口 `Limiter` | `Limiter` 接口可换 Redis 实现 |
| 调用链 → ClickHouse/ES | `SpanStore`（有界内存） | `AddBatch` 逐条容错，修正生产里的整批失败 |

## 3. 明确没有复刻的内容

1. **K8s / Istio / Knative / CRD / EnvoyFilter**：需要 Docker/K8s 集群，本机不具备。
2. **microVM 隔离与 <1ms 冷启动**：需要 KVM/Firecracker 类能力。
3. **企业 IAM / mTLS / 证书链**：简化为 API Key + grants。
4. **真实 LLM 推理 / vLLM / SGLang**：用 Mock LLM。
5. **MySQL/Redis/ClickHouse/ES/Thanos 集群**：用文件+内存，接口抽象保留替换点。
6. **多租户配额计费 / 成本大屏**：只做限流与 token 计量，不做账单。
7. **卫星调度算法**：科研背景，不属于本次复刻范围。

---

## 4. 为什么这样替代是合理的

- **协议层用官方 SDK**：比内部实现更规范（[A2A 官方 SDK 列表](https://github.com/a2aproject/a2a/blob/3303592588e388e62e0f69f701af531d2f4e3991/docs/sdk/index.md)、[MCP 官方 SDK 分级](https://modelcontextprotocol.io/docs/2026-07-28/sdk.md)）。
- **数据面用纯 Go 过滤器链**：保留了你简历里最有价值的「Envoy Filter 语义 + SSE 修复 + 实例复用」，又绕开无 gcc 限制。
- **Store / Limiter / ConfigSource 都是接口**：把"本地文件"换成"Redis/MySQL/xDS"只需换实现——这本身就是平台解耦能力。
- **所有踩过的坑都有回归用例**：把排查经验固化成自动化测试，比复刻基础设施更有说服力。
