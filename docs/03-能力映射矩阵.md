**来自历史对话的排查故事 → 代码里的修复**

| 故事 | 简历/对话中的现象 | 本实现的正确处理 | 测试 |
|---|---|---|---|
| SSE 被 `SendLocalReply` 掐断（`curl (18)`） | 流式响应中途连接断开 | `AppendEncodedData` + `Continue`，**禁止**响应开始后写新 HTTP 状态 | E10 |

| 手改配置被 `created-by: agentrun` reconcile 覆盖 | 改了不生效 | 数据面不读本地手写运行时配置，只认 `/v1/config` 快照 | E21 |
| 统一地址转换（改写 `:authority`/Host） | 虚构地址映射 | `TransformFilter` 显式改写 Host/路由目标，并有测试 | E08 |
| `EnvoyFilter apply` 409 | 多来源冲突 | 配置单向下发，无多写方 | E21 |
| span 整批插入失败（`getDuration()` null 拆箱 NPE） | 前台 span 缺失 | 数值字段非指针 + 逐条容错 `AddBatch` | E23 |

**来自历史对话的排查故事 → 代码里的修复**

| 故事 | 现象 | 本实现的正确处理 | 测试 |
|---|---|---|---|
| `bufio.Scanner: token too long` | 64KB 上限，128KB artifact 行导致 curl 卡死 | `NewNDJSONScanner` 用 `Buffer(64K, 10M)`；另提供 `NDJSONReader.ReadBytes` 无上限实现 | E11 |
| `/tasks/{id}:cancel` 冒号路径 panic | Go 1.26 `ServeMux` `bad wildcard segment` | 单前缀 handler + `ParseRestPath` 手动解析，LastIndex 切冒号 | E12 |
| `The request object has been recycled` | Tomcat 异步响应提交后访问 request | 流生命周期内不缓存请求对象，响应提交后只读不可变快照 | E09 |
| `NoSuchBeanDefinitionException` 时序问题 | Bean 初始化与 ThreadLocal 上下文竞态 | Sidecar 状态用显式 context 传递，不依赖线程局部 | E24 |
| protobuf `VerifyError` 版本冲突 | `Struct` 不能赋给 `GeneratedMessage` | 固定依赖版本 + `go mod tidy`/`mvn dependency:tree` 校验 | build |
| A2A Sidecar 404 | `/agentbox/.../agent-card/list` `No static resource` | 契约固定 `/.well-known/agent.json` 与 `/a2a/{id}` | E02 |
| 跨服务 TLS `PKIX path building failed` | 证书未导入 | 本地全 HTTP；生产映射文档说明 cacerts/trustStore | 文档 |
